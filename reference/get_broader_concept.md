# Function to get the direct broader concept of a specific concept

\`get_broader_concept()\` get a dataset containing the direct broader
concepts of a specific concept.

## Usage

``` r
get_broader_concept(concept)
```

## Arguments

- concept:

  a parsed concept

## Value

An object representing the parsed json body of the broader concept.

## Examples

``` r
if (FALSE) { # \dontrun{
get_broader_concept("https://id.erfgoed.net/thesauri/dateringen/1196")
} # }
```
